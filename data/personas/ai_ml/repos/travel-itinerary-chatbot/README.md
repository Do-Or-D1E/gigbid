# Travel itinerary chatbot with tools

Small service built for a travel team that needed to let travellers plan and change a multi-city trip by chatting with an assistant that can check live availability.

## Stack

- OpenAI API
- FastAPI
- LangChain

## Getting started

```
pip install -r requirements.txt
python chain.py
```

## Layout

- `src/chain.py`
- `src/pipeline.py`
