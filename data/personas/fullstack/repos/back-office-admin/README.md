# Back-office admin for a law firm

Internal tooling from a legal engagement. Goal: give staff one internal tool for matters, deadlines and client documents.

## Stack

- Django
- React

## Getting started

```
npm install
npm run dev
```

## Layout

- `src/components/MatterList.jsx`
- `src/tests/e2e/checkout.spec.js`
- `src/utils.py`
