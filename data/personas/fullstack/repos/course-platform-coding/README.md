# Course platform for a coding bootcamp

Internal tooling from an edtech engagement. Goal: sell cohort-based courses and release lessons on a schedule.

## Stack

- Stripe
- Django
- PostgreSQL

## Getting started

```
npm install
npm run dev
```

## Layout

- `src/cache.js`
- `src/docker-compose.yml`
- `src/main.py`
- `src/openapi.yaml`
